## 📌 About the Project

Steel Plate Fault Detection is a Machine Learning project that focuses on identifying and classifying defects in steel plates using structured manufacturing data.

The project explores how machine learning can support industrial quality inspection by analyzing defect characteristics and predicting different fault categories.

### 🎯 Objectives

* Analyze steel plate defect data.
* Perform data preprocessing and exploratory data analysis.
* Develop machine learning classification models.
* Evaluate model performance using suitable metrics.
* Explore AI applications in industrial quality control.

## 📊 Dataset

The project uses the **Steel Plates Faults dataset** from the UCI Machine Learning Repository.

* **Instances:** 1,941
* **Input features:** 27
* **Defect categories:** 7
* **Task:** Multiclass classification

**Defect categories:** Pastry, Z-Scratch, K-Scratch, Stains, Dirtiness, Bumps, and Other Faults.

🔗 [Dataset Source — UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/198/steel+plates+faults)
